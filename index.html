เกี่ยวกับการเรียนวิชา Full Stack Web Development

1. เหตุผลที่อยากเรียน Full Stack Web Development

เหตุผลที่อยากเรียนวิชานี้เพราะต้องการเข้าใจภาพรวมของการพัฒนาเว็บไซต์ตั้งแต่ต้นจนจบ ตั้งแต่การออกแบบหน้าตาเว็บไซต์ส่วนหน้า (Frontend) ที่ผู้ใช้งานมองเห็น ไปจนถึงการจัดการระบบหลังบ้าน (Backend) และการเชื่อมต่อฐานข้อมูล (Database) การเรียนรู้ทั้งสองส่วนจะช่วยให้สามารถสร้างเว็บแอปพลิเคชันที่สมบูรณ์ได้ด้วยตัวเอง และเป็นทักษะสำคัญที่เป็นที่ต้องการอย่างมากในสายงานเทคโนโลยีปัจจุบัน

2. ความคาดหวังต่อวิชานี้

คาดหวังว่าจะสามารถนำความรู้ที่ได้ไปสร้างโปรเจกต์เว็บไซต์ที่ใช้งานได้จริง มีความเข้าใจในโครงสร้างการทำงานของระบบเว็บ สามารถเชื่อมต่อ API และจัดการข้อมูลได้อย่างปลอดภัย รวมถึงได้ฝึกฝนการทำงานร่วมกับผู้อื่นและการใช้เครื่องมือมาตรฐานอย่าง Git เพื่อเตรียมความพร้อมสำหรับการฝึกงานและการทำงานจริงในอนาคต

3. จุดอ่อนที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

จุดอ่อน: ยังขาดความชำนาญในการวางโครงสร้างโค้ดให้เป็นระเบียบเมื่อโปรเจกต์มีขนาดใหญ่ขึ้น และบางครั้งยังใช้เวลานานในการแก้ไขข้อผิดพลาด (Debugging) เมื่อเจอปัญหาที่ซับซ้อน
แนวทางการพัฒนา: จะฝึกเขียนโค้ดให้สม่ำเสมอมากขึ้นผ่านการทำโจทย์และโปรเจกต์ขนาดเล็ก ฝึกอ่าน Error Message อย่างละเอียดเพื่อหาสาเหตุของปัญหา และศึกษาโค้ดตัวอย่างจากนักพัฒนาคนอื่นบน GitHub เพื่อเรียนรู้วิธีเขียนโค้ดที่ดีและเป็นระบบมากขึ้น

เว็บไซต์ที่ชื่นชอบและแรงบันดาลใจ

เว็บไซต์ที่ชื่นชอบและใช้เป็นแหล่งเรียนรู้ในการเขียนโค้ดคือ MDN Web Docs (Mozilla Developer Network) เพราะเป็นแหล่งรวบรวมเอกสารและคู่มือเกี่ยวกับ HTML, CSS และ JavaScript ที่ละเอียดและเข้าใจง่ายมาก
